# M1.2 guided Rust/C++ lesson

Five implementation locations connect validated external text to the existing
renderer. Excerpts are literal source; the C++ comparisons describe familiar
concepts rather than additional implementations. See the
[compatibility report](m1.2-nl2-import.md) for the numerical assumptions.

## 1. Own the input buffer and bound file reads

[`crates/qx-geometry/src/diagnostic_import/mod.rs`, line 20](../crates/qx-geometry/src/diagnostic_import/mod.rs#L20)

```rust
pub fn read_text(path: &Path) -> Result<String> {
    let file =
        std::fs::File::open(path).map_err(|e| GeometryError(format!("{}: {e}", path.display())))?;
    let mut bytes = Vec::new();
    file.take(MAX_INPUT_BYTES as u64 + 1)
        .read_to_end(&mut bytes)
        .map_err(|e| GeometryError(format!("{}: {e}", path.display())))?;
    crate::ensure(
        bytes.len() <= MAX_INPUT_BYTES,
        "diagnostic input exceeds 32 MiB",
    )?;
    String::from_utf8(bytes).map_err(|e| GeometryError(format!("input must be UTF-8: {e}")))
```

`&Path` borrows a path without taking it from the caller. `File::open` returns an
owned RAII handle, like `std::ifstream`. Calling `take` moves that handle into a
reader that stops after the limit plus one byte. `&mut bytes` grants temporary
exclusive access to the vector, comparable to passing `std::vector<uint8_t>&`.
`?` returns an error immediately; `map_err` supplies context. `String::from_utf8`
consumes the buffer and validates encoding instead of retaining an unchecked
`char*`. The next line closes the function; all handles are released on errors.

## 2. Parse rows into typed values before accepting geometry

[`crates/qx-geometry/src/diagnostic_import/csv.rs`, line 111](../crates/qx-geometry/src/diagnostic_import/csv.rs#L111)

```rust
            let v = line
                .split(delimiter)
                .map(csv_number)
                .collect::<Result<Vec<_>>>()?;
            ensure(v.len() == columns, "incorrect CSV column count")?;
```

`line` is a borrowed `&str`; splitting does not copy the input. `map(csv_number)`
returns a `Result<f64>` for each cell. Collecting into `Result<Vec<_>>` stops on the
first bad number and otherwise produces an owned numeric vector. In C++, this
resembles a loop appending parsed doubles while returning `std::expected` on
failure. The column count is checked before indexing. The adjacent `frame`
function checks finite unit axes, orthogonality and handedness before bounded
normalization. NL2's left becomes minus QUANTUM lateral; world positions stay
unchanged. Native quaternion/vector consistency is checked separately.

## 3. Borrow XML strings, then own persistent identifiers

[`crates/qx-geometry/src/diagnostic_import/support_xml.rs`, line 282](../crates/qx-geometry/src/diagnostic_import/support_xml.rs#L282)

```rust
        let start = required(n, "start")?.to_owned();
        let end = required(n, "end")?.to_owned();
        let a = self
            .nodes
            .get(&start)
            .ok_or_else(|| GeometryError(format!("beam start {start} must precede beam")))?
            .position_m;
```

`required` initially returns a string slice tied to the parsed XML's lifetime.
`.to_owned()` produces an independent `String`, like copying a `string_view` into
`std::string`, so the imported beam can outlive the DOM. `get(&start)` borrows the
map key and node; `ok_or_else` converts absence into a useful error. `Vec3` is a
small `Copy` value, so reading `position_m` copies three doubles rather than
moving a node out of the map. Duplicate IDs, bad dimensions and references that
appear too late fail before a scene is installed. XML never resolves external
entities or loads a prefab path.

`alignment(&ImportedTrack, &ImportedSupports)` receives shared immutable borrows,

allocating pairs. The projection fraction is clamped to the segment, producing

it cannot shift or snap the borrowed source geometry. `Option<f64>` distinguishes
an unavailable connector orientation from a measured zero. Missing track indices

## 5. Adapt into existing construction and share the completed scene

[`apps/quantum-x/src/diagnostic_import/mod.rs`, line 58](../apps/quantum-x/src/diagnostic_import/mod.rs#L58)

```rust
        let generated = track.construction_track();
        let mut mesh = construction::build_with_assets(
            &generated,
            &definition,
            Default::default(),
            &qx_rendering::construction_assets::Sources::new(&root),
        )?;
        if let Some(s) = &supports {
            s.append_mesh(&mut mesh)?;
```

The following braces close the `if` block. `construction_track` creates an owned
sample adapter with empty Regions and measurements. `&generated` and `&definition`
are read-only borrows; `&mut mesh` grants the support adapter exclusive temporary
access. Both use the same mesh types and GPU renderer as native construction.
The loader later moves the finished mesh into `Arc::new(mesh)`, like
`std::shared_ptr<const Mesh>` when shared immutably. GPU upload caching can reuse
the same allocation. Reload builds on a worker, then transfers ownership through
a channel only on success. Clearing drops references; no manual `delete` or
project serialization is needed.

command in the report. Source geometry and simulated vehicle state are separate
throughout this path.
